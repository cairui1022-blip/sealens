方法论与数据口径

数字标注体系

  • 事实来源直接给出、可公开验证。
  • 推算由事实计算得出（如年化运行率、收入倍数）。
  • 自报创始人/官方自填，未经第三方验证。
  • 推测我们的判断或待核实占位，非事实。

双日期口径

收入数据每日更新并标注「收入截至」；定性拆解资料单独标注「资料截至」，两者不混用。
